## OJ 与交互式学习平台

确认日期：2026-09-25。状态：已实现，本地验收通过。

目标：在博客内边阅读边实践。左侧展示当前文章、算法讲解或课程内容；右侧提供对应的代码编辑器或交互终端，能够输入、编译或执行，并查看真实结果。

### 已确认范围

- [x] **左右分屏学习**：左侧保留正在阅读的内容，右侧进行练习，不必反复切换文章与开发工具。
- [x] **数据结构与算法 OJ**：结合现有 C/C++ 课程，在右侧编写代码、编译、输入测试数据、运行并查看输出；展示编译错误、运行错误和测试结果。
- [x] **Git 命令练习**：提供可操作的练习仓库与终端，输入 Git 命令并查看实际输出、仓库及分支状态变化。
- [x] **Linux 命令练习**：提供交互终端与练习文件系统，输入课程中的命令并观察输出和文件变化。
- [x] **Go 学习支持**：后续扩展 Go 语法及示例的编辑、编译和运行。
- [x] **MySQL 学习支持**：后续扩展 SQL 输入与执行，查看结果表、错误提示以及数据和表结构变化。
- [x] **练习记录**：配套测试用例和提交记录，保留失败代码与修正版本，方便重做和复盘。

### OJ 内置娜娜莉小助手

确认日期：2026-09-25。状态：已实现，本地验收通过。与下方娜娜莉智能构造体升级共用记忆和任务能力。

- [x] **随时提问并理解当前练习**：在 OJ 中提供娜娜莉助手入口，遇到不会的地方可直接提问。结合左侧文章或题目、右侧当前代码或命令、所选语言、测试输入与最新执行结果回答，减少重复粘贴上下文；覆盖算法、Git、Linux、Go 和 MySQL 练习。
- [x] **讲解怎么写**：支持询问实现思路、具体写法、命令用法和 SQL 语法；可按用户要求给出分步提示、代码或命令示例及解释。用户明确要求写法时给出可操作的回答，辅导方式可按确认的偏好调整。
- [x] **及时指出错误**：编辑时对可由语言工具确定的问题进行即时诊断和行内标注；编译或执行返回后立即显示编译错误、运行错误、命令错误、SQL 错误及测试失败，并由娜娜莉解释原因和修改建议。能定位时指向对应行或片段；测试失败展示失败输入以及实际与预期结果。诊断必须对应当前代码或命令版本，区分工具确认的错误与 AI 推测的逻辑问题，不把尚未执行的代码说成已经验证。

### 运行方案

已采用独立 Node.js 私有后端和 Docker 隔离运行器，支持 C/C++、Go、Git/Linux 与 MySQL；代码版本和持久工作区版本分别检查，状态使用原子写与版本冲突保护。具体部署、资源限制和真实测试证据见 [后端说明](features/learning-backend.md)。

## 娜娜莉智能构造体升级

确认日期：2026-09-25。状态：六项均已实现，本地验收通过。目标是让娜娜莉成为有持续记忆、能理解当前情况、跟进目标、调用工具并验证结果的个人智能体。

- [x] **1. 统一的记忆**：让前台聊天、后台任务和 OJ 共用持续保存的记忆，覆盖用户确认的偏好、学习进度、未解决问题、执行经历和纠正记录。重要记忆保留来源与时间，支持修改和删除；区分行为观察、推测与确认事实。私有记忆采用独立私有存储，不直接写入公开仓库；支持跨会话及设备接续。
- [x] **2. 理解当前情况**：接入当前文章、日程及 OJ 的题目、代码版本、提交、输入和真实测试结果，使追问能够接续实际上下文；不能仅凭阅读时长或访问次数判断用户不会或已掌握。
- [x] **3. 持续目标与任务**：持久保存目标、步骤、进度、卡点、下一步和恢复点，支持跨天继续、暂停、取消与调整。明确区分待办和已启动任务，只有用户明确启动或已有对应授权时才推进。
- [x] **4. 行动与验证**：提供明确的检索、资料读取、练习准备、测试运行、笔记保存和复盘整理工具，按授权调用；读取实际执行结果后决定下一步。生成练习时验证参考解和测试用例，记录失败与未完成状态，完成声明必须有结果依据。
- [x] **5. 从经历中调整方法**：结合明确反馈、实际结果和后续纠正，更新教学策略并积累可复用的处理方法；优先通过记忆、策略与经过验证的工具流程实现，不能把经验记录描述成模型已自动训练或能力已得到验证。
- [x] **6. 稳定的人格与表达**：将现有的人格和交互规则统一到聊天、后台工作、随笔与 OJ 辅导中；技术准确性优先，表达随当前情境调整，语音、表情及 Mao 联动跟随真实任务状态，共同经历以实际记录为依据。

实现：独立后端保存私有记忆、事件和任务状态。前台消息与用户显式启动的步骤调用模型或工具；现有后台定时任务可通过可选配置共享允许公开的记忆与人格，并写回实际行动摘要。目标可跨页面和跨天恢复，页面关闭后不自动重放未完成步骤。操作方式和隐私边界见 [娜娜莉工作室](features/nanaly-agent.md)。
