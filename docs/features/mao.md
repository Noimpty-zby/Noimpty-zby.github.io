# Mao 看板娘

Mao 是博客角落里的 Live2D 陪伴角色；Nana 负责聊天和解释。Mao 的界面本身不会自动发送聊天、朗读文章或调用模型服务。解释、总结等功能需要你主动点击，再交给 Nana 处理。

## 日常操作

- 点击左下角的帽子可以显示或收起 Mao。帽子旁的小齿轮打开「设置与快捷操作」。
- 轻点人物保留分区互动；双击人物打开 Nana 对话。右键人物、聚焦后按回车，或点击小齿轮可打开快捷操作；聊天或朗读期间单击也会打开快捷卡。
- 拖动人物调整位置；也可以在设置里选择左右侧、人物大小和离底部高度。
- 使用键盘可以逐项访问按钮、选项和滑块。按 `Escape` 或点击关闭按钮收起面板，焦点回到打开它之前的位置；点击面板外部关闭时不会抢走新的焦点。
- 小屏面板会收窄并允许内部滚动。浏览器缩放或可视区域变化后，面板会重新限制到可见区域内。

## 快捷操作

| 操作 | 使用方法 |
| --- | --- |
| 解释选中内容 | 先在正文里选中文字，再右键人物或点击小齿轮，然后点击此项。点击入口之前的选区会保留，最多使用前 6000 个 UTF-16 码元，保持 emoji 完整并明确提示截断；没有选区时只显示提示。 |
| 总结当前文章 | 主动将当前页面的阅读请求交给 Nana；具体可用范围由聊天入口判断。 |
| 打开学习日程 | 打开博客的学习日程。 |

快捷卡不把选中的文字插入 HTML。操作尚未完成时，卡片会暂时禁用重复点击；失败会保留卡片并给出提示。

## 陪伴设置

| 设置 | 含义 |
| --- | --- |
| 站在哪边 | 选择左侧或右侧。 |
| 人物大小 | 小、中、大三档。 |
| 离底部高度 | 0% 靠近底部，100% 靠近顶部。 |
| 收成小挂件 | 手动切换紧凑显示。 |
| 窄屏自动收起 | 在较窄的页面中自动使用紧凑显示。 |
| 互动时播放语音 | 控制 Mao 的互动语音，打开开关本身不会播放。此项与 Nana 的回复朗读分开。 |
| 跟随 Nana 聊天状态 | 用表情回应聊天的进行状态，不会因此发起聊天或开启朗读。 |
| 主动说一句的间隔 | 不主动说话，或约 70 秒、2 分半、5 分钟。实际触发还受安静模式和页面状态限制。 |
| 安静陪伴 | 暂停闲聊与自动招呼，保留主动互动和聊天时的回应。 |
| 性能模式 | 自动或省电。省电减少动画负担，后台暂停由人物运行时负责。 |

偏好保存在本机 `mao-settings-v1`，兼容原来的可见性和语音开关。设置由 Mao 主模块校验、持久化，再刷新界面。控件模块没有另存一份偏好，也不保存聊天密钥。加载状态会显示在面板顶部；加载中或失败时可以点击「重新加载」，一次重试结束前不会重复提交。

## 聊天、语音与真实进度

- Mao 跟随 Nana 的思考、流式回答、完成、取消和失败状态，气泡只展示当前简短内容；恢复历史不会重播庆祝。快捷阅读使用当前聊天话题，因此保留已有会话历史、确认记忆和已经发送的附件上下文，草稿附件不发送。
- 已有朗读启动后，Mao 共用该段音频和语气结果，不额外生成一份回答或音频。支持 joy、sadness、comfort、surprise、serious、embarrassed、teasing、annoyed 等实际语气标签；相同表情不重复启动渐变。
- 支持音频捕获的浏览器使用真实波形音量驱动嘴型；不支持时，仅在确实播放期间使用轻微口型动画。缓冲、暂停、停止和后台状态会闭嘴；回到前台可以接回当前朗读。
- 聊天优先于 Mao 的互动语音；Mao 不打断正在规划、加载或播放的聊天语音。模型忙于聊天或朗读时暂停音乐带动的摆动和闲聊，背景音乐播放开关仍由播放器控制。
- 课程提示读取当前页面构建出的实际篇数，不把文章数量说成学习完成章节。日程以解锁后的快照为准，编辑后即时更新；勾完任务或数据明确记录新文章时可以庆祝，至少间隔 60 秒，安静模式不主动庆祝。

## 显示与恢复

窄屏默认收成 88 像素头像，点头像可以在当前页面展开，设置也能手动收起。拖动结束自动靠近左边或右边，保存高度比例；方向键也可以移动。正常渲染上限 60 FPS，省电、头像、减少动态或省流量模式上限 24 FPS，并减少视线跟随和音乐摆动；进入后台暂停人物更新和渲染。

运行库等待超过 20 秒、模型等待超过 30 秒会显示失败，可在齿轮面板重新加载。关闭期间完成的旧模型会被释放；重试中的共享贴图按所有权统一释放，避免迟到请求把新人物变成白屏。WebGL 画面中断也提供重试入口。

## 代码接入

`source/js/mao-controls.js` 暴露 `window.MAO_CONTROLS.create(options)`。它不创建 Live2D 模型，也不直接使用聊天或语音服务。

```js
const controls = window.MAO_CONTROLS.create({
  button,                      // 现有帽子按钮
  getSettings,                 // 返回当前已校验的偏好
  onSettingsChange,            // 接受局部 patch；可返回 Promise
  onAction,                    // 只在用户点击快捷操作时调用
  getStatus,                   // { phase, message }
  onRetry                      // 用户主动重试；可返回 Promise
})
```

返回 `open()`、`close()`、`showActions()`、`refresh()`、`destroy()`。`open()` 展开完整设置，`showActions()` 显示快捷卡并折叠设置；主模块变更设置或加载状态后调用 `refresh()`。卸载时调用 `destroy()`，移除追加的节点与全局事件监听。

`onAction` 接收 `explain-selection`、`summarize` 或 `schedule`；只有解释操作附带 `{ text }`。返回 `false` 或抛出异常时保留面板并显示失败提示；成功后关闭面板。如果外部操作已把焦点移到 Nana，关闭不会把焦点抢回。

`getStatus()` 的 `phase` 为 `idle`、`loading`、`ready` 或 `error`；`message` 按纯文本显示。`onSettingsChange(patch)` 接受下列字段，最终验证和保存由调用方负责：

```js
{
  side: 'left' | 'right',
  size: 'small' | 'medium' | 'large',
  bottomRatio: 0..1,
  compact: boolean,
  autoCompact: boolean,
  voice: boolean,
  chatSync: boolean,
  idleSeconds: 0 | 70 | 150 | 300,
  quiet: boolean,
  power: 'auto' | 'saving'
}
```

在 Butterfly 的 `inject.head` 中，`mao-controls.css` 放在 `mao-pet.css` 之后；`inject.bottom` 中，`mao-controls.js` 放在 `mao-pet.js` 之前。控件颜色沿用博客现有配色，没有额外运行库。

## 验证边界

`tools/tests/media/mao-controls.test.mjs` 使用本地 DOM 替身运行离线行为回归，覆盖选区保留与长度、空选区保护、显式动作与重复点击、设置类型、状态与重试、焦点恢复、窄屏定位，以及销毁后的异步回调。测试不会实际发送聊天、调用语音、访问模型服务或执行部署。

本轮还验证了真实浏览器中的 Live2D 渲染、桌面与 390px 窄屏布局、设置持久化、拖动吸边、选区操作、状态联动和画面重试。本地 WAV 验证了实际波形读取和口型；没有调用真实付费聊天或 TTS，也没有对所有手机浏览器和硬件做性能测试。

## 可爱互动（已实现）

登记日期：2026-09-25。以下 8 项现已实现。打开小齿轮，选择「陪 Mao 玩一会儿」进入互动面板；也可直接在人物上摸头、拖动或叫醒她。

- [x] **1. 投喂小零食**：把小饼干或小鱼干拖到 Mao 面前；她先看着零食，靠近后吃掉，出现碎屑和爱心。连续投喂时抱着剩下的零食说“这个留到下午吃”。
- [x] **2. 有过程的摸头反馈**：鼠标在头顶轻轻来回移动时逐渐眯眼、脸红、冒出小花；停止后抬头看一眼，说“……摸完啦？”。偶尔扶正帽子，假装什么也没发生。
- [x] **3. 与博客樱花互动**：现有飘落樱花偶尔停在帽子上；Mao 抬眼看、晃脑袋，用户点掉花瓣后露出笑脸。低概率出现伸手接花却没接住的小剧情。
- [x] **4. 被拎起来的反应**：拖动时表现为被拎住帽子，身体轻晃、露出惊讶表情；放下后缓一下并整理帽子，说“搬家之前先说一声嘛”。整体动作保持轻微。
- [x] **5. 偷偷打瞌睡**：安静陪伴一段时间后逐渐闭眼，出现小小的 Zzz 和云朵气泡；轻点后突然清醒，说“我有在看……！”，随后保留一点迷糊的状态。
- [x] **6. 逗猫棒小游戏**：从小菜单拿出逗猫棒，视线跟随羽毛，靠近时扑一下；扑空时短暂不服气，抓到时出现星星眼。一次互动约十几秒。
- [x] **7. 偶尔递来小纸条**：低频探出一张折好的纸，点开后展示歪歪扭扭的小猫、爪印或“今天的好运分你一半”等短句；纸条可收进小相册。
- [x] **8. 合影小相机**：点击相机后摆表情并倒数，偶尔在倒数时换鬼脸；生成带日期、小爪印和手写风格短句的拍立得样式照片，支持保存。


### 互动使用与保存

- 小饼干既可用鼠标/触摸拖到 Mao 面前，也可直接点按投喂；小鱼干提供点按入口。两分钟内连续投喂三次，她会把余下的零食留起来。
- 鼠标在头顶轻轻往返会逐渐触发摸头反馈；键盘和触摸可用「轻轻摸头」完成同样过程。拖动仍使用原来的吸边和高度保存，新增的拎帽、摇晃和整理动作不会改变保存方式。
- 首页现有 `.sakura-petal` 的动画循环偶尔带来一片落帽樱花，两次至少间隔 90 秒；菜单也可主动接花。花瓣可点掉，没操作时约 22 秒后收尾。少数接花会扑空。
- 约两分钟没有互动时，她会慢慢打瞌睡；点人物或云朵可以叫醒。菜单可主动让她打盹。逗猫棒每局 15 秒，支持移动指针、方向键和回车，接近羽毛会扑一下并记录抓到次数。
- 小纸条低频出现，至少间隔约八分钟，正在玩或打开菜单时不会自动递来。点开后可主动收藏；菜单随时可查看纸条和相册。最多保留最近 24 张，使用 `mao-play-v1` 在本机保存纸条种类、日期和最近的投喂计数；存储受限时给出提示并保留当前页面的临时收藏。
- 相机倒数三秒后用 Pixi 的真实人物画面生成 720×900 PNG，加上日期、爪印和短句。预览完成后由用户点击保存；照片不上传、不写入 localStorage，新照片和人物关闭时会释放旧预览资源。

小游戏文本和表情在本地完成，不发起聊天或语音请求。安静陪伴、减少动态、省电、省流量和紧凑头像不会触发自动小游戏；主动选择的互动仍可使用，减少动态时去掉摆动和漂浮效果。聊天/朗读优先于小游戏；开始聊天、切后台、关闭人物和 PJAX 导航会取消当前互动与倒数，迟到的照片回调不会重新弹出结果。双击人物仍可打开 Nana。

### 互动模块与验证

`source/js/mao-play.js` 的 `window.MAO_PLAY.create(options)` 由人物加载完成后创建、随人物关闭销毁。模型实例、坐标、表情、逐帧参数和画面导出均从 Mao 主模块传入，不另建 Live2D 或音频运行时。动作只使用官方素材中已有参数；额外装饰为轻量 DOM/CSS。脚本顺序为 `mao-play.js`、`mao-pet.js`（`mao-controls.js` 仍在人物脚本之前），`mao-play.css` 跟在现有 Mao 样式之后。

### 正在执行的任务

持久目标的每次实际执行和独立出题会发布 `nanaly:agent-activity`，Mao 只响应当前页面实时开始的任务。执行期间暂停主动游戏与闲聊，显示思考状态；完成、失败和取消各自收尾。聊天和真实朗读保持最高优先级，任务事件不会替换音频嘴型。切后台时停止显示，回来只恢复仍在执行的状态，不重播旧结果或后端历史。关闭聊天表情联动也会继续暂停与任务冲突的小游戏。

调用 `NANALY_AGENT.activity({ id, phase, text })`，其中 `phase` 为 `thinking`、`complete`、`error` 或 `cancelled`；同次执行共用唯一 `id`。无参数读取当前状态，返回 `busy` 与 `current` 表示是否仍有活动及最近开始的活动。重复终态、没有实时开始的终态不会发送事件；重叠活动按各自 `id` 收尾。状态只在内存中维护，连接切换会取消本页活动，不写入远程记忆或历史。
