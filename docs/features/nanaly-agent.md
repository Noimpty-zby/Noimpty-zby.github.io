# 娜娜莉工作室

聊天工具栏的「工作室」和练习台的「连接 / 管理个人后端」打开同一个面板。后端部署方式见 [私有后端](learning-backend.md)，练习界面见 [边读边练](learning-lab.md)。

## 连接与统一记忆

填写 HTTPS 后端来源地址和访问令牌；本机测试允许 localhost 的 HTTP。连接验证成功后，后端地址和令牌只保存在本标签页的 sessionStorage 中；同一标签页切换站内页面或刷新时，在站点门禁解锁后自动恢复，只读取最新状态，不重放运行或其他操作。恢复验证完成前显示连接中，成功后才显示绿色已连接。地址另可保存在本机，私有记录保存在仓库外的后端数据目录。

主动锁定或断开会清除会话凭据，认证失效也会清除；临时网络故障保留会话，联网后可重新验证。关闭标签页后会话通常结束，但浏览器恢复标签页可能保留会话；需要立即退出时请点击断开。浏览器禁用会话存储时仍可使用当前连接，面板会提示换页后可能需重新连接。

令牌也可以存进聊天设置里的密钥保险箱（「个人后端令牌」一栏），和模型密钥一起用解锁密码加密，localStorage 里只有密文。保险箱解锁或保存后会自动连接后端；打开页面时保险箱已解锁、站点暗号已开且尚未连接，也会自动连接。在本标签页手动断开过，就不再自动连回去，直到再次手动连接或重新解锁保险箱。明文令牌不会写入 localStorage 或私有状态快照；本机备份会带上保险箱密文，恢复后仍需解锁密码。

连接后，原聊天「记忆」面板和工作室共用同一份记忆。偏好、确认事实、目标、未解决问题、纠正和学习进度有来源及更新时间，可编辑、删除。本机原有确认记忆通过「合并本机已确认的记忆」主动导入，不自动上传历史对话或附件。

另一设备更新了状态时，本次保存会明确报告冲突并加载新版本，不以旧快照覆盖。网络失败保留表单供重试。断开或更换后端会清除本页私有列表和表单草稿，避免把旧服务资料误存到新服务。

每轮聊天会读取可用的后端记忆、已启动或暂停的目标、确认过的教学经验、实际行动记录、日程及当前练习快照。刷新失败会标明资料是最近一次快照。模型收到的是背景数据；未确认推测、阅读停留和访问次数不被当作掌握程度。

## 跨天目标与真实工具

1. 登记目标，添加明确步骤；此时状态是待启动。
2. 点击「启动 / 恢复」，再点击「执行下一步」。一次只执行一个已列明的步骤。
3. 可暂停、取消、调整名称或写下恢复点。重新连接后继续查看下一步、卡点和实际结果。

工具包括阅读当前文章、检索博客/网络、生成并验证练习、运行当前练习测试、保存笔记和整理复盘。网络检索与模型使用现有娜娜莉服务商配置；代码测试使用个人后端。

步骤只有在真实工具返回结果并成功持久化后才会标记完成；全部步骤完成才完成目标。超时、中断或存储冲突会保留失败/未完成状态。执行步骤有五分钟租约，另一标签页不能立即重复执行。刷新后不自动重放可能有副作用的操作；租约到期后由用户显式重试。保存笔记使用步骤编号防止重试产生重复记录。

当前目标由页面内控制器推进；关闭页面后保存恢复点，不宣称服务器会自动继续任意目标。现有后台日程、巡逻等仍按原来的定时流程运行。

## OJ 辅导、出题与经验

练习台的提问会传入本次题目、语言、代码版本、输入以及真实执行结果，之后可在同一聊天继续追问。编辑后的代码与旧结果分别标识。工具确认错误和 AI 逻辑推断保持区分；没有执行结果时不会描述为通过。

「请娜娜莉出题并验证」支持 C、C++、Go。模型给出题面、起始代码、完整参考解和 2–8 个用例；后端真实编译并逐个运行参考解，全部通过后才载入题目。运行编号、题面、参考解和用例保存在云端提交历史；起始代码仍显示尚未执行。通过这些测试不证明题面或覆盖全面，用户仍可纠正。模型响应无效、验证失败或取消时，不载入“已验证”题目。

工作室中的经验表单保存用户确认的教学方法与依据，例如“先给最小反例，再解释边界”。这些策略会进入后续上下文，可删除。它是可审查的经验记录，不是模型自动训练。

## 后台一致性与隐私

聊天、OJ 和后台模型统一使用 `source/js/nanaly-identity.js` 的身份与准确性规则，保留各场景原有表达要求。Mao 跟随实际聊天、步骤执行和出题验证状态；忙碌时暂停主动互动，聊天与真实语音优先，不把历史恢复当成新的完成事件。

在已有 GitHub Actions 中配置可选 secrets `NANALY_AGENT_URL` 与 `NANALY_AGENT_TOKEN`，即可连接同一个后端。后台公开回复与随笔仅取得标记了「允许用于公开回复与随笔」的确认记忆和经验；默认私有。任务执行后的摘要事件保存到私有后端，失败也明确记录；同步失败不抹去现有任务日志。这里的代码变更不自动配置 secrets、发消息或部署。

导出按钮可下载不含令牌的私有 JSON 备份。正式托管前还应配置主机数据备份；运行历史有数量与容量上限，不作为永久作品仓库。

## 验证

离线测试覆盖同标签页换页与刷新恢复、门禁检查、连接验证及并发去重、断开与迟到响应隔离、网络和认证失败、会话存储拒绝与损坏、连接切换、CAS 冲突、旧响应不回退新版本、暂停与取消、步骤租约、记录格式、公开记忆过滤和出题验证流程。真实模型费用没有包含在离线测试中；付费模型响应质量应在用户配置服务商后验收。
