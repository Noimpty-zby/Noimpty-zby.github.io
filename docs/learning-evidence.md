# 错题现场与成长回放

入口：`/learn/` 代码小屋、`/review/` 实际重做队列、`/growth/` 成长回放。页面外壳可构建；私人代码、输入和输出不会进入 Hexo 文章、公开 JSON 或远程分析。

## 留下一个真实现场

1. 在代码小屋运行程序，展开“错题现场 · 保存与复盘”。可填现场标题、题目与复现步骤、标准输入和本次复盘。
2. 交互程序结束后可以保存真实失败。若要精确保留标准输入/测试结果，使用“按标准输入运行并记录结果”；Git、Linux、MySQL 也走现有隔离后端，取得真实结果。
3. “保存失败现场”保存的是显示时间对应的运行快照。运行后又修改的代码不会冒充已经运行的版本。单纯语法检查、连接错误或主动停止没有可保存的执行结果。
4. 修正并重新运行后，选择“保存这次重做 / 修正”。初次失败保持不变，新的代码、输入、输出和解释追加为下一次尝试。

代码运行与“执行通过”来自既有隔离服务；本地备份只保留其结果，不声称重新验证了导入文件。终端输出保存最多 64 KB，超过上限明确标记；终端输入是实际按键序列（可能含编辑控制符），重做时需要重新输入。使用批量执行保存的标准输入和测试则可原样恢复。

## 真正重做与 FSRS

`/review/` 的“回到真实现场重做”列出到期操作题。点击后打开 `/learn/?case=记录编号`，载入**最初失败**代码、题目和可重放输入/测试，不展示旧修正答案；原语言草稿进入恢复点。

一次独立重做必须真实运行并保存，才能评分。未通过只能选择“重来”；通过后可选“困难 / 良好 / 简单”。同一次运行不能重复评分。FSRS 从这些真实重做对应的评分记录推算到期时间，与知识问答卡独立存储，翻卡不会算完成操作题。

成长页默认收起旧代码，提供“先重做这道题”。完成后展开“重做后对照不同尝试”，可选任意两次尝试，并排查看代码、实际输入输出、测试和当时解释。曾经修正过的题仍会按计划回来。

## 备份与存储

「讲给娜娜莉听」2026-10-02 删掉了，成长回放也不再显示讲解。存讲解的接口（下面的 `recordExplanation` 等）和数据结构先留着：以前导出的备份里可能有讲解，删掉的话这些备份就导不回来了。

所有现场与讲解保存在同源 IndexedDB `noimpty-learning-evidence-v1`。原来的练习草稿、云端执行记录和问答卡 localStorage 不会被迁移、清空或覆盖。评分、追加尝试、导入使用 IndexedDB 读写事务；多标签页追加不会互相擦除，同一次重做只评分一次。

成长页可导出全部现场与讲解，再在另一台已解锁的设备“合并导入备份”。导入先校验再原子合并，重复导入不重复计数；编号冲突、损坏数据或配额错误会令整次导入回滚。页面只在事务真正提交后显示保存成功。浏览器禁止存储或空间不足时保留现有数据库并提示失败；可以重试或导出已有内容。备份包含私人源码，应按私人文件保管。

## 集成接口

先加载 `learning-history.js`，再加载 `learning-lab.js` / `review.js`，最后加载 `learning-history-ui.js` 和 `learning-history.css`。FSRS 包仅按需加载。`/growth/` 遵循现有全站私有门禁。

- `NOIMPTY_LEARNING_HISTORY.summary()`：未解锁返回 `null`；已解锁只返回数量和最近时间，绝不返回源码/输入/输出。字段为 `cases, due, solved, attempts, explanations, dueExplanations, latestAt`。
- 每次事务提交/其他标签页变更派发 `learning-history:changed` 和兼容事件 `noimpty:learning-history`，事件不携带私有正文。
- `get(id), list(), saveFailure(attempt), addAttempt(id, attempt), rate(id, attemptId, rating)`：门禁保护的错题接口；写失败拒绝 Promise。
- `recordExplanation({confirmed:true, topic, source:{title,url}, explanation, feedback, reviewQuestions, revises?})`、`getExplanation(id)`、`listExplanations()`：确认后追加讲解；`revises` 指向早先记录，形成成长链。来源 URL 仅允许本站。

回归测试包括 IndexedDB 的跨标签追加/重复评分竞争、配额失败回滚、损坏与冲突备份、门禁、解释追加链、真实运行快照保存、恢复草稿保护、默认隐藏答案、实际操作队列和异步离页清理。
