# 2026-09-25 练习台改为代码小屋

用户希望把练习台用作轻量 IDE，进入后选语言、写代码、真实运行，不再展示题目、示例、参考解或测试用例编辑面板。

## 行为与界面

- `/learn/` 改为代码小屋：语言选择、编辑器、输入／终端／记录。新语言默认空白；已有草稿与历史保留，刷新恢复最后使用的语言。
- CodeMirror 6 自托管，支持 C、C++、Go、Git、Bash、MySQL 的语法高亮、补全、缩进、括号匹配、撤销和 Ctrl／Command + Enter。Escape 后按 Tab 可离开编辑器，语言之间的撤销历史隔离，超过 65536 字符的编辑拒绝，避免屏幕代码与实际发送代码不一致。
- 默认奶油樱粉配色，更多菜单可切夜樱紫，独立于站点按时间自动变暗。自动语法检查默认关闭，可在更多中开启。
- 文章中的“边学边练”在原页面形成两个不重叠的实色栏；文章 DOM 保留原位，支持独立滚动、拖动／键盘调整宽度。手机切换文章与代码。关闭、PJAX、页面离开清理编辑器及分屏状态。
- 保留娜娜莉上下文、历史恢复和已验证练习载入的兼容 API；无题目时上下文使用文件名与空 problem，不再注入示例题。
- 后端协议、鉴权及隔离执行环境不变。依赖许可证随编辑器 bundle 分发；`npm run build` 自动重建 bundle。

## 验证

- 项目 76 个测试文件通过；练习台控制器 27 项包含空白默认、语言草稿隔离、刷新恢复、自动检查偏好和已有并发取消边界。
- 构建、186 个 HTML 的站内链接检查、公开页面泄漏检查通过。
- 独立 Edge 在完整本地构建页面中验证高亮、草稿切换／刷新、真实云端 C 运行、编译诊断跳行及修改后旧结果失效。运行使用 `saveHistory:false`，未调用模型或保存云端运行历史。
- 浏览器验证桌面／手机、文章节点保持原位、实色无浮层、分隔条键盘调整、关闭与 PJAX 清理，无页面 JavaScript 错误。
- 编辑器独立浏览器检查包含补全、Tab／Shift-Tab、撤销、超长粘贴及空文档切换语言后的撤销隔离。

本地整页验收使用临时测试暗号，生产门禁沿用 GitHub Actions 的现有 secret；测试暗号未写入源码配置。
