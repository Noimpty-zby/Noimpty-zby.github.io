# 2026-09-25 学习平台与娜娜莉升级验收

## 开发完成范围

[项目待办](../backlog.md) 的 16 项学习平台/智能体需求，以及 [Mao](../features/mao.md) 的 8 项互动需求均已实现。保留既有博客、聊天、语音和本机记忆行为，并增加可选的私有后端连接。

- 六种真实练习环境：C、C++、Go、Git、Linux、MySQL；支持文章分屏、草稿、版本对应的诊断、测试、取消、提交历史和持久工作区。
- 娜娜莉工作室：私有统一记忆、当前练习上下文、持久目标和步骤、经实际结果确认的工具行动、教学反馈与统一人格。目标由用户明确启动并逐步执行；关闭页面后可恢复记录，不在服务器自动执行任意目标。
- 出题先验证完整参考解和测试，载入后的学生起始代码仍明确显示尚未执行；编辑中不覆盖新草稿。即时检查默认开启，保留手动关闭的偏好，只做支持语言的工具检查，不自动运行 SQL 或请求付费模型。
- Mao：投喂、摸头、落花、拖起、打盹、逗猫、纸条收藏和真实合影；真实任务忙碌时暂停主动互动，聊天和语音优先，取消后收尾，不重播历史完成事件。

- `npm run check`：75 个测试文件全部通过；Hexo 构建通过，产出 704 个文件、184 个 HTML；17,447 个站内链接无死链，公开页面泄漏检查通过。
- 常规测试中的两个真实 Docker 入口按约定跳过；另行显式运行 `NANALY_DOCKER_TESTS=1 node --test tools/tests/server/docker*.integration.test.mjs`，8 项真实容器测试全部通过，不能把默认跳过视为集成验收。
- 覆盖鉴权、精确 Origin、状态版本冲突、原子持久化与备份恢复、工作区隔离、旧响应丢弃、跨标签页步骤租约、取消竞态、输出/时间/资源上限及公开记忆过滤。
- 真实容器验证六种课程参考样例，GCC/Go 编译错误，超时及输出上限，Git/Linux 文件状态接续，MySQL 表/过程/事件及中文数据恢复；验证不同用例不共享可写文件，非 root、无 capability、只读根目录、无外部网络、无宿主仓库或访问令牌。脚本写入后取消不会提交新快照。
- 代理控制器 18 项、Mao 115 项、练习控制器 23 项及助手流程 9 项相关行为测试通过；已检查补丁空白错误。

## 浏览器验收

- 使用临时本地令牌连接真实后端，登记目标、保存笔记步骤、明确启动并执行；刷新后重新连接，完成状态和结果能够恢复。
- C 样例真实运行 3 个测试通过；改成未声明变量后，真实 GCC 错误定位到第 2 行，点击诊断可定位编辑器；修改后的版本不会沿用旧版本的通过状态。
- MySQL 实际建表、写入、查询和查看表结构，中文结果正确；历史保留运行依据。
- 390 像素视口显示上下排列，页面没有横向溢出；另行验证文章分屏和 PJAX 清理。
- 新连接后的默认工具检查确实发送 `mode:check`；切到 MySQL 后等待防抖，不自动执行 SQL；无页面 JavaScript 错误。
- Mao 实际投喂、纸条收藏、Live2D 倒计时合影和真实 PNG 预览通过；下载链接已生成，未把浏览器自动化未确认的系统文件落盘写成验收成功。

## 上线与费用边界

本地开发验收完成时尚未购买服务器或域名。随后用户购买腾讯云新加坡 2 核 8 GB 服务器与域名，私有后端已完成 rootless Docker 部署及公网 HTTPS 验收，详见 [后续生产部署记录](2026-09-25-production-deployment.md)。本轮前端已发布，用户确认无需本机备份后已完成 `https://noimpty-zby.cn` 主域名切换、有效 HTTPS 与正式组件到云端 API 的联调。本文的浏览器结果仍是本地验收证据；本地 Docker Engine 和 `nanaly-runner:1` 镜像已按用户授权保留。

模型回答、助手上下文和出题流程已通过可控替身进行行为验证，未调用真实付费模型。真实服务商的回答质量和浏览器跨公网设备接续仍待后续验收；云端 API HTTPS 已在后续部署阶段单独验收。

开发验收时的预算建议：先考虑腾讯云海外入门型 Linux 2 核 4 GB（官方页面列价 42 元/月），香港同级别列价 90 元/月；前者给模型费用留出更多余量。具体地域、库存、线路体验和结算价以购买页为准，域名和模型用量另计。价格依据：[腾讯云轻量应用服务器计费说明](https://cloud.tencent.com/document/product/1207/73452)，查询日期 2026-09-25。先按月试用，不依赖首年促销价估算长期成本。

实际购买选择为新加坡 2 核 8 GB、80 GB SSD，首个购买周期 1 个月、72 元；域名和模型调用另计，后续续费以账单为准。
