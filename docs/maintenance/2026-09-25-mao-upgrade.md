# 2026-09-25 Mao 六项完善

## 功能

1. 聊天状态桥接：思考、流式回答、完成、取消和失败；短气泡节流、旧轮隔离，锁定后不展示正文。
2. 复用现有语音播放、语气结果和缓存，真实 RMS 音量口型、实际情绪映射、不支持分析时降级；聊天优先于互动语音。
3. 读取当前课程页面真实篇数与解锁后的日程快照，编辑即时同步；删除过时的固定进度台词。
4. 独立轻量设置面板，大小、左右位置、高度、语音、聊天联动、闲聊频率、安静、省电、紧凑和窄屏自动收起；拖动吸边和本机保存。
5. 解释选区、总结当前文章、打开日程；选区在失焦前保留并明确提示截断；有真实数据依据的完成与发布庆祝共用冷却。
6. 运行库与模型加载超时、错误提示、重试、后台暂停、24/60 FPS 上限；取消与重试时管理共享贴图所有权。

实现分别归入 `source/js/mao-pet.js`、`mao-controls.js` 和原聊天/语音/日程模块，样式在相应 CSS；说明在 `docs/features/mao.md`，测试继续按功能分类。
