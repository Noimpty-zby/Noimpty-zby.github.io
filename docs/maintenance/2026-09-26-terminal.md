# 2026-09-26 代码小屋改成终端式的 IDE

后端运行记录显示，用户在 Linux 里是一条一条地试命令：`pwd`、`cd test`、`touch test1`，然后连着三次 `nano test1` 和一次 `code .`，都得到 `command not found`。原来的 Git/Linux 是「编辑器 + 执行整段脚本」，没有键盘输入，也没装编辑器；C/Python 的输入要先写进「输入」框。这次把整个小屋改成以终端为中心：Git/Linux 是真正的交互式 Bash，C/C++/Go/Python 在终端里编译运行并直接读键盘。用户随后要求「别让我学了一个知识点却无法验证」，又补了手册、工具和 `code` 命令。

## 行为

- Git/Linux：xterm.js 终端，工具栏「终端 / 脚本」切换，按语言记住。提示符 `learner@nanaly:~$`，工具栏显示终端所在目录；`nano`、`vim`、`man`（含 `man -k`）、Tab 补全（含 Git 子命令）、`↑` 历史、`Ctrl+R`、`less`、`tail -f`、`tmux`、`htop`、`make`；时区为北京时间。选中后 Ctrl+C 复制，Ctrl+V 粘贴；触屏多一排 Tab/Esc/Ctrl+C/Ctrl+D/Ctrl+L/方向键；终端字号可调，手机默认 12 px。
- 终端不随网页结束：刷新、换页、分屏开合后回来，屏幕和正在跑的命令都在；断线自动重连，只补发缺的输出。离开 30 分钟或开满 3 小时才保存关闭，`exit` 后按任意键重开。目录、导出变量、别名、函数、命令历史和文件都保存。
- 「脚本」模式是编辑器在上、同一个终端在下，「在终端执行」把命令粘进终端执行。
- `code 文件名` 在网页编辑器里打开该文件，Ctrl+S 写回；回放的旧输出里的请求不会再次打开文件。
- C/C++/Go/Python 的「运行」在下方终端里显示 `gcc … && ./main` 等并执行，程序读键盘，结束显示退出码与用时；「停止」或 Ctrl+C 结束。原来的「输入」页去掉，下方面板为「终端 / 输出 / 记录」。
- 没有 root、不能联网：`sudo` 是一个说明没有 root 的小脚本；`apt install`、`git clone https://…`、`curl`/`ping` 外网都不可用。

## 实现

- `server/lib/websocket.mjs`：手写的 RFC 6455 服务端（部署不带 node_modules）。`server/lib/terminal.mjs`：票据与 WebSocket，Shell 的文件读写。`server/lib/pty-session.mjs`：一个 PTY 程序的输出缓存（256 KB，按字节偏移补发）、多页面共享、无人时的超时。`server/lib/sessions.mjs`：Shell 容器（快照恢复、结束时保存）和一次性的程序运行容器，以及终端开着时的 `/api/run`。
- `server/runner/shell-session.py`：`terminal` 增加 `--pidfile`、窗口标题；新增 `pty` 动作跑任意程序。
- Dockerfile 在 PyTorch 层之后加一层：去掉最小化镜像的手册排除并重装常用包、`man-db manpages manpages-dev`、`nano vim bash-completion tmux htop psmisc lsof strace make tzdata`，`/usr/local/bin/code` 与 `sudo` 两个小脚本，`TZ=Asia/Shanghai`。
- 前端：`learning-lab.js` 重写布局与终端连接（`createTerminalLink`：自动重连、补发、退出、程序运行），`learning-terminal.js` 为按需加载的 xterm.js 包（标题、OSC 7337、粘贴、字号），编辑器增加纯文本模式和 Ctrl+S。

## 没做的：root 与联网

曾按「真正能跑所有 Linux/Git 命令」设计过常驻学习机（sudo 免密、容器联网、可写根文件系统、apt 装的软件保留）。Claude Code 的自动模式安全检查把它判为削弱沙箱，没有继续；这需要用户明确决定。风险在于：令牌一旦泄露，拿到的就是服务器上一台能联网、有 root 的机器（rootless Docker 下 root 仍是受限用户）；若要做，还应在部署脚本里挡住云厂商元数据地址（169.254.0.0/16）、给 slirp4netns 开 ping、并给磁盘设保护线。

## 验证

- 本地：`shell-terminal.test.mjs`（真实 PTY 的 bash 与 `pty` 动作、pid 文件）、`terminal.test.mjs`（WebSocket 帧；票据；Shell 断开不结束、只补发缺的输出、新页面拿到整屏、两页共享输入、`exit` 保存、在开着的终端里执行脚本、`code` 读写、重置结束终端；Python 程序读输入、停止、离开即结束；无人超时保存、关停保存），经 `tools/tests/server/local-docker.mjs` 用本机目录代替容器跑真实 API；`learning-lab.test.mjs` 的终端连接用例。
- 浏览器（本地构建 + 本地后端 + 无头 Chromium）：Linux 终端、`code` 打开并保存文件、刷新后屏幕和目录都在、脚本模式、Python 与 C 在终端里读输入、深色、手机宽度、Git 文章分屏；页面零报错。
- 真实 Docker 部分由 `docker-terminal.integration.test.mjs` 在部署时于服务器上跑：提示符与窗口标题、uid/TERM/时区/窗口大小、无网络、手册与 `man -k`、`sudo` 说明、`code` 的 OSC、nano 保存、在开着的终端里执行脚本、脚本接着终端的目录和变量、历史跨会话、运行中挂断仍保存、Git 仓库与 Tab 补全、C/Go/Python 读输入。本机没有 Docker 权限，这一项只在服务器上执行。
