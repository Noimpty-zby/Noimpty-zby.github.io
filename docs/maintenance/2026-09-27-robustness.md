## 修复结果

### 后端并发、取消与资源释放

- Shell 和程序会话在启动阶段串行准入，避免多个请求同时绕过数量限制；同语言任务替换等待旧任务清理，服务关闭等待已经接受的启动结束。
- 启动异常及清理失败时仍释放工作区锁和并发名额。Docker 删除失败的容器继续受跟踪，允许后续关闭时重试。
- 在共享 Shell 中执行脚本时，提前取消及准备源码、读取目录期间取消，都不会继续执行后续步骤；结束逻辑即使遇到清理错误也会释放资源。
- PTY 输入队列限制为 1 MiB，超过时挂断，避免程序不读取输入时主机缓冲无限增长。
- 修复 WebSocket 升级附带第一帧早于监听器的问题；补充异常 URL、非法关闭码、关闭原因 UTF-8 和空分片边界；关闭后停止积累输入并释放缓冲。
- 编辑器保存文件先完整接收，再在同目录写临时文件并原子替换；传输不完整不会先截断原文件。保留原文件权限和符号链接指向，读写命令异常明确返回失败。

主要位置：`server/app.mjs`、`server/lib/{sessions,runner,pty-session,terminal,websocket}.mjs`。新增 `session-boundaries.test.mjs` 等故障回归。

### 前端异步状态与功能完整性

- 终端取票据及连接共享 30 秒期限，关闭会取消未完成连接；过期回调、握手失败和连续重连均有边界。
- 编辑器与终端组件按需加载，加载期限为 20 秒，失败可重试。编辑器升级保留正在输入的草稿、语言、反向选区和焦点；关闭后不会再挂载迟到组件，失败时仍可使用基础文本框。
- 等待终端期间切换语言，不再误执行旧脚本。
- 附件内存缓存最多 48 项，内容字符串总长度上限为 24 × 1024²；临时附件占满时拒绝新增并保留已有内容。持久化恢复后可正常写入，超大持久化文件不驻留内存，删除后的在途读取不再回填旧条目。此预算按字符串长度计，不是浏览器实际堆内存字节数。
- 智能体联网搜索的取消与 45 秒期限传递给真实请求；取消后的排队复盘不再落盘。
- 加密备份补齐 Python 草稿和运行历史的导出、校验及恢复。
- 日程本地缓存失败时显示持久提示，避免用户把内存中的草稿当成已保存；PJAX 离页后仍保留必要的关闭提醒。
- Mao 的辅助日程请求包含正文读取的 20 秒期限；超时释放共享请求，允许重试，迟到数据不能覆盖新状态。

主要位置：`learning-lab.js`、`nanaly-files.js`、`noimpty-ai.js`、`nanaly-backup.js`、`schedule.js`、`mao-pet.js` 及相关回归。

### 检查、日报与部署工具

- 站内链接检查支持单引号、无引号、大小写属性、实体编码、同源协议相对地址及懒加载地址；忽略注释和脚本正文中的假链接，拒绝空构建和空页面，每个 HTML 仅读取一次。

## 验证边界与后续事项

- 浏览器工具连续三次连接失败（`nodeRepl.fetch request failed`），未获得真实页面。本轮交互状态由生产代码与 DOM 替身回归覆盖，真实浏览器布局、焦点和输入仍待验收。
- 共享 Shell 内脚本的取消通过匹配脚本进程终止；主动脱离、改名或后台守护的后代进程不保证全部退出。需要强进程树终止时应另行设计会话隔离。
- 原子文件替换会更换 inode；硬链接关系不保留，多页面同时编辑仍是最后一次成功保存生效，没有文件版本冲突提示。
- 链接检查不覆盖 CSS `url()`、`srcset`、`base href` 或运行时生成的地址；公开页检查也不等于完整安全审计。
- 审查阶段没有调用收费语音或模型服务，没有重新执行联网依赖漏洞审计；以下本地结果不代替公网生产验收。真实 Docker 本地测试与生产 rootless、代理和网络配置仍有差别。
