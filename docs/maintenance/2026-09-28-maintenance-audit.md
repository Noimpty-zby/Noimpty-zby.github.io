## 修复

- 学习台仅在实际换页时释放编辑器和连接。取消、失败和未替换页面的 PJAX 完成事件不再清空未保存草稿或移除入口。
- 内页小角色在导航取消后恢复交互；鼠标移出取消待执行动画帧；实时响应减少动态效果和页面可见性变化，清理粒子、字幕定时器与动画。
- 文件/图片 IndexedDB 在升级、意外关闭后可重新连接；被阻塞请求迟到成功时关闭旧连接，避免妨碍重试。
- 文件缓存读取校验记录身份、格式、正文和扫描图上限；坏记录不送入模型，原数据不删除。取消后的旧附件错误提示不再串入新话题。
- C 普通运行链接数学库，与交互终端一致；真实 `sqrt` 输入程序验证此前链接失败、本轮修复有效。
- 共享终端脚本补语言、工作区身份、版本和关闭状态检查；准备源文件时取消也返回取消状态。
- 脚本运行使用现有 Python 运行环境监督进程组及被收养的子孙进程，覆盖启动前取消、运行中取消、超时、自然退出和脱离进程组的后台进程。监督进程异常结束时回收共享终端容器，并按真实保存结果返回状态；没有增加第三方运行依赖或扩大容器权限。
- 巡逻无法获取清单/讨论、疑似限流及贴表情失败会准确使任务失败；正常无问题巡逻跳过不必要的 Discussions 请求。
- 后端部署补齐旧环境缺失的镜像配置，保留回滚；`--help` 只显示帮助，未知或多余参数在测试、Git、SSH 前失败。
