# 娜娜莉聊天工作区

## 连接模型

打开娜娜莉 → 设置，在“硅基流动 API Key（图片问答）”填写自己的密钥并用原保险箱密码保存。默认视觉配置为：

- 接口：https://api.siliconflow.cn/v1
- 模型：Pro/moonshotai/Kimi-K2.6

2026-09-19 根据硅基流动官方文档选定；模型可在高级设置中替换。文字聊天继续使用原文字配置；图片及近期图片追问使用视觉配置。只配置硅基流动也可以文字聊天。密钥分别保存在同一个本机加密保险箱里，不应写入仓库。图片发送与检索规划均可能产生模型费用。

官方依据：[视觉输入](https://docs.siliconflow.cn/docs/userguide/capabilities/vision)、[当前图文示例](https://docs.siliconflow.cn/docs/userguide/capabilities/text-generation)、[模型调整公告](https://docs.siliconflow.cn/docs/release-notes/overview)。

## 对话与资料

普通问题可以触发只读的博客检索、文章阅读和联网搜索，无需输入固定前缀。“全站搜一下：”和“上网搜：”仍可指定范围；联网搜索需要 Tavily 密钥。每次最多三轮规划、五次工具执行。回复下方的来源卡使用实际检索的 URL 与原文片段；引用编号无法对应时明确提示，不把“未检索到”当作“没有写过”。

话题保存在本机，可新建、切换、改名、搜索历史、引用消息和修改问题。每个话题保留最近 120 条消息；送入模型的历史另有窗口和字符预算。清空当前话题有 15 分钟撤销期。收起窗口继续回答，停止按钮会中止请求；切页、锁定会停止当前请求。发送时立即保存问题，失败或中断可重试、继续。

“记住：”“更正：”“待办：”会打开确认表单。只有确认的内容进入长期记忆，可在“记忆”中编辑或删除；阅读停留和访问次数不会被当作已确认的偏好。对话、记忆、图片均不自动同步到仓库。

## 图片

支持按钮选择、粘贴和拖入 PNG/JPEG/WebP，每轮最多两张、原图每张 10 MB。图片在本机重新编码、压缩并去掉元数据，点击发送后才交给视觉服务。压缩图保存在 IndexedDB，历史只存引用。图片存储不可用时会说明刷新后需要重新附加。锁定或设置时隐藏待发送预览。清理会同时核对当前和持久化的所有话题、待完成轮次与撤销记录，保护其他标签页的图片。

## 链接检查

在文章中点击“检查本文链接”或发送同名请求。检查范围是当前已发布文章的站内链接与图片，最多 24 项；站外链接和超限项明确列为未检查，不宣称全站健康。

配置的 GitHub token 对该仓库具有 Actions 读写、Checks 读取权限时，会派发 nanaly-article-check.yml；工作流本身只有 contents:read 和 checks:write，不发评论、不修改文章。没有凭据或权限时可以在浏览器检查当前页面。任务卡展示真实状态、检查范围、时间和结果，后台结果必须匹配请求编号、运行编号和提交 SHA。刷新页面只恢复记录，点击“刷新任务状态”才联网核验。停止等待不会假装取消已经运行的后台任务。

## 验证

npm test 包含工具循环、Provider 密钥隔离、图片存储、话题恢复、流式停止/失败、任务派发与来源接续的离线回归。真实服务可用性、账号权限和识图质量仍需使用自己的密钥验证；测试不依赖真实密钥或付费请求。
