包含哪些数据

API 密钥保险箱的原密文、模型设置、聊天话题与草稿、确认记忆与阅读记录、日程未同步修改、练习草稿与记录、文章检查任务、Mao 纸条收藏与模型用量账本，以及浏览器已保存的图片和文件内容。

附件是站内保存的 JPEG 图片、文档解析文字与页图，不是原 PDF / DOCX。已经丢失或尚未成功存入浏览器的附件无法补回。声音与外观偏好、站点解锁状态、服务器上的目标/笔记/运行环境不在本机备份范围。

工作室中的“导出私有记录备份”只备份已连接后端的记录，与本页用途不同。

2. 校验文件，或在新域名恢复

可在旧域名校验下载的文件，不会改动任何记录。恢复仅支持空白目标；已有聊天、密钥或附件时会停止，不会合并或覆盖。

导出前请保留好原保险箱密码。无需解锁 API 密钥即可备份或恢复。

为避免浏览器内存不足，完整备份正文上限为64MB；超过上限会停止并说明，不会省略附件后假装完整。恢复中请保持页面打开。
