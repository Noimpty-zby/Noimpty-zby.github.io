## 面试与求职干货

- **小红书测试开发岗的 MySQL 最低门槛清单，正好拿来当复习顺序** —— 这篇讲 2026 年小红书职级和测试开发面试的文章，把 MySQL 底线要求列成一句话：索引为什么用 B+Tree、联合索引、最左匹配、索引失效、事务、隔离级别、MVCC、慢 SQL、Explain。薪资数字没说。这个清单不是只对测试开发有用，它基本就是后端岗通用的 MySQL 高频考点。他现在 Linux 还在补，MySQL 一行没碰，按目前水平这九项里大概一项都答不顺，但正好可以当「学完即够」的检查表：先把 B+Tree、最左匹配和 Explain 弄明白，再啃事务隔离级别和 MVCC。我觉得这条标题蹭小红书职级有点虚，但清单本身比培训机构凑的八股诚实得多，值得直接塞进学习笔记当目录用。 [来源 · developer.aliyun.com](https://developer.aliyun.com/article/1765237)

- **「项目里写了 AI，面试官顺着往下问」，他简历越空越容易踩这个坑** —— 知乎这篇拿 6 年 Java 的人举例：项目里一旦写了 AI，面试官就会顺着工程细节往下挖。素材里举的是线上接口慢、MySQL 没明显异常，还继续追问「看哪些日志」「会用什么命令」，原帖没给标准答案。这对他的警醒比任何 MySQL 八股都直接：他简历工程侧现在是空的，以后要是硬把 AI 或推理服务写上去，这种「看日志、上命令」的追问一问就穿帮。他补 Linux、Git、MySQL 的时候得把排查路径记下来，而不是只记命令。我觉得这篇标题有点标题党，但那个追问链条是真的，他做小项目时最好逼自己写下「怎么定位线上慢」那一段，不然简历上写 AI 就是给自己埋雷。 [来源 · zhuanlan.zhihu.com](https://zhuanlan.zhihu.com/p/2085048135471125834)

## 工程实践与踩坑

- **Go 为什么敢开一百万个 goroutine** —— 素材里讲的是 Go 栈帧与逃逸分析：C 的线程栈在线程创建时就固定下来，通常 8MB，之后只涨不缩；Go 如果照这个规格给每个 goroutine 预留，一百万个就是 8TB 虚拟内存，所以它必须换一套做法（具体换成什么、怎么涨怎么缩，素材没说）。对他来说这条的价值不在「学会逃逸分析」——他 Go 一行没写过，现在啃栈帧纯属浪费。价值在于它把「为什么 AI Infra 的并发服务用 Go 而不是 C++ 线程模型」这个前提讲清楚了：一个推理网关要同时挂住上万个连接，线程模型先死在内存上，这跟他课内操作系统里那套「进程/线程」不是一回事，是他换方向后要重新建立的直觉。我觉得这条先当「知道有这么回事」存着就行，等他真写完第一个 Go 服务、被内存打脸一次再回来读，那时候才看得进去。 [来源 · bbs.csdn.net](https://bbs.csdn.net/weixin_28745067/article/details/100309026)

- **Go 的 database/sql 默认会把整个结果集读进内存** —— 素材里的作者在用 Go 写一个 20MB 的单文件数据库管理工具，说踩过最大的坑是结果集内存占用：`database/sql` 的默认行为是把查询结果一次性全部加载到内存。他没说数据量多大、也没说最后怎么改的。对他意味着什么：这是他 MySQL 那条线上第一个「书上看不到、只有动手才会撞到」的坑，而且撞法很典型——本地几十行数据完全正常，一上真实数据就爆。他现在还没到写数据库代码的阶段，但这条可以先记成一个待验证的问题：等他把 MySQL 索引那部分看完、开始写第一个带查询的后端小接口时，拿一张几十万行的表试一次，看内存怎么涨。我觉得这比再读十篇索引原理有用，因为面试官问「你踩过什么坑」的时候，能说出这个的人不多。 [来源 · bbs.csdn.net](https://bbs.csdn.net/weixin_31960565/article/details/100316421)

## 能上手的小项目

- **Git Worktree：从底层原理到上手** —— 素材讲的是 Worktree 的原理与坑：平时一个仓库目录对应一个工作区，`git checkout` 切分支会把工作区文件整个替换掉，所以同时开多个分支干活很别扭；Worktree 让一个仓库挂多个工作区，代价是每个都要重装依赖（前端 `node_modules` 几百 MB 一份，Rust 的 `target` 目录更夸张，几个 Worktree 能吃掉几百 G）。他的 Git 学到分支与合并、解冲突，正好卡在「想同时开两条线」的位置，Worktree 是这一步之后最自然的延伸；但素材里没有命令级的上手步骤，只有痛点和现象。我觉得这篇现在看性价比一般 —— 他连 stash 和 reset 都还没碰，先把手头的分支循环练熟，Worktree 等真需要同时改两件事再说。 [来源 · x.com](https://x.com/realchendahuang/article/2100776341348245679)
