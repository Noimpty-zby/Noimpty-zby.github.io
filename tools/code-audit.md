# 代码健壮性审查记录

日期：2026-09-19。范围：项目自有前端、Hexo 构建脚本、娜娜莉自动化、日报、检查工具、工作流与依赖。本记录对应此次代码健壮性改造；测试与内容保护结果记录如下。

## 内容保护

对 `source/` 中除 JavaScript/CSS 以外的 204 个文件逐一保存并复核 SHA-256。所有博客 Markdown、资讯、数据文件、图片、音乐等均与修改前完全一致；没有新增内容文件。博客笔记没有改写。

## 已修复

### AI 对话与搜索

- 统一一轮请求的取消和超时。检索期间停止不会继续启动模型，清空/设置/锁保险箱后旧请求不会回写。
- SSE 支持拆开的 UTF-8、CRLF、多行事件和缺少末尾换行；收到 DONE 即释放流，异常也释放 reader。
- 中断保留已有回答；长度截断及服务端过滤标明未完成，不执行不完整回答中的动作。
- 修复 Markdown 行内代码与链接替换顺序导致的属性注入/字面内容被改写；资源加载失败可重试。
- 配置、历史、记忆、用量存储校验；错误密码不替换内存密钥，保存期间锁定不重新写回密钥。
- 损坏的日志行不阻断聊天；索引/日志共享请求有 20 秒上限，超时后可以重试，单个读者取消不破坏其他读者。
- reset 同时使文章摘要、站点地图和日志缓存失效，并阻止旧异步结果回填。
- 搜索失败不会误说文章从未写过；修复英文大小写、单字查询与脱离 DOM 的正文提取。
- 设置时禁用发送、中文输入法确认不误发、焦点与滚动恢复；手机输入区不被入口按钮遮挡。

### 日程、隐私门、播放器和页面

- 日程保存/加载使用基线合并，保留未保存草稿及保存期间继续输入的改动；异常远端数据不会以空表覆盖草稿。
- 日程 JSON 与搜索、行动日志共用 AES-GCM 信封。无暗号不发布日程/日志，搜索为空；源数据不变。
- 手动撤销自动完成后保留标记，后台不重新勾上；真正修改完成条件时清除旧标记，新规则可继续生效。回复按真实时间和北京时间任务日期匹配，旧回复、未来回复、缺失或非法时间不会误勾任务。
- 构建、日报和浏览器统一校验真实日期、任务结构及全表唯一 ID；损坏数据不覆盖草稿，不显示正常空表。
- 课程完成条件正确切换控件，移动端七课程网格从桌面四列切为平板两列、手机一列。
- 隐私门忽略外站、新标签和修饰键点击；口令轮换使旧会话失效，存储不可用时不无限刷新。
- 搜索拦截严格比较同源和 GET 请求，尊重调用方取消。
- 播放器容忍损坏缓存，元数据未就绪时不把恢复位置清零，旧播放请求失败不覆盖新曲目状态。
- 修复嵌套 TOC 滚动坐标、远程封面 URL/CSS 转义、统计重复初始化与异常心跳时间戳。

### 娜娜莉后台与日报

- 讨论、评论、回复、表情完整分页，检查游标和异常响应，避免漏回和重复回评。
- 批注严格校验返回 JSON、段落索引、重复和条数；损坏的已有批注表会停止处理，不清空覆盖。
- 短文章不耗尽单轮名额，草稿和未来文章不发送给模型；保留已有内容。
- 生成 Markdown 使用真实块结构净化，修复错误围栏、引用链接、协议相对链接和来源 URL 边界；在站点和娜娜莉的实际渲染环境下验证。
- 日期解析识别非法日历日期和时区；Git 使用 NUL 分隔避免中文文件名被引号转义；新文章过滤未来/草稿。
- 模型返回有类型校验、重试和超时上限，截断/被过滤输出不用于生成完整产物；过滤不重复请求，后续成功不抹掉此前失败的诊断信息。
- HTTP/格式错误不当作零评论或正常健康状态；未知流量历史不当作从未记录过。
- 失败、超时或仍执行中的部署不再显示全部成功；检查不完整保留警告。
- 日报邮件连接有超时；回访邮件链接指向对应文章。
- 自动化入口对拼错的演练参数或多个动作立即失败，避免误触发正式执行。

### 构建和自动化

- daily-round 在 bash 严格模式下仍执行全部步骤，最终正确返回失败。
- 自动工作流统一 npm ci，邮件和 Markdown 直接依赖纳入锁文件；设置作业时限。
- 公开仓库不上传包含私密日程的报告，即使运行失败也不上传。
- 静态资源监听构建清理哈希缓存；锁清单用内容指纹，换暗号后不会继续取旧清单。
- 损坏批注不使页面渲染崩溃；子路径部署重定向不重复 root。
- 检查工具拒绝坏锁清单、缺失公开页面，站内 URL 使用严格 origin 判断。
- npm run build 自动清理 Hexo 缓存，消除旧板块列表沿用错误链接的问题；新增 npm run check 一键验证。

### 依赖与资源

- 替换旧 Hexo Markdown renderer 为本地兼容适配器，统一使用 Markdown-it 15，保留原 MIT 版权声明。
- 对全部 72 个 Markdown 文件（含 30 篇博客笔记）做旧/新渲染对比，输出逐字一致；额外覆盖公式、任务列表、图片、重复标题、跨文章隔离和长输入。

- 移除未启用的 Gitalk/Valine/LeanCloud 等旧依赖链。2026-09-19 锁文件的 npm audit 由 25 项已知漏洞降至 0。
